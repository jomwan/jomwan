### 🚀 Featured Projects

#### 🛡️ [Enterprise Real-Time Fraud Detection](https://github.com/jomwan/Fraud-Detection)
* **Stack:** Python, PyTorch (LSTMs), XGBoost, Neo4j, Redis, Kafka, Streamlit, Docker
* A real-time distributed fraud detection system engineered using a Hybrid AI Ensemble (Supervised, Unsupervised, Deep Sequential, and Graph Learning) on a Medallion Data Lakehouse Architecture.

#### 📊 [Databricks Fraud Ingestion Pipeline](https://github.com/jomwan/databrick-fraud-detection)
* **Stack:** PySpark, Delta Live Tables (DLT), MLflow, Unity Catalog, Streamlit
* A cloud-native implementation of the Medallion Data Lakehouse on Databricks with real-time transaction ingestion and multi-model AI ensemble inference.

#### 📈 [TikTok Trend Diffusion ABM](https://github.com/jomwan/TikTok_ABM)
* **Stack:** Python, Mesa, Solara, Plotly, NetworkX, Selenium
* An Agent-Based Model (ABM) simulating how viral TikTok trends convert to consumer purchases during Thailand's Songkran festival.

#### ⛳ [Golf Bookr Bangkok](https://github.com/jomwan/golf-bookr)
* **Stack:** React 18, Node.js, WebSockets, MySQL, Google Gemini 3.5 Flash API
* A premium online booking system and AI concierge (CawFee AI Assistant) for Bangkok's elite golf courses.

#### 💻 [Premium Data Science Portfolio](https://github.com/jomwan/Portfolio)
